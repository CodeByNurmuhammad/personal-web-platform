You can now play Halo in a browser tab.

Technology · 24 November 2026 · 10 min read

No install. No console. Here’s how AI turned a months-long reverse-engineering job into an overnight run.

0installs needed
240 fpsSimpsons: Hit & Run port, reportedly
Months → hoursdecompiling effort, per Kotaku

The storyWhat happened?

On October 8, X user @RadiantOpti posted a thread: Black Ops zombies, Skate 3, Halo and Modern Warfare 2 now run in a browser tab. The list kept growing: Vice City, The Simpsons: Hit & Run, Quake, Half-Life, even Diablo.

The trick isn’t streaming video from a server. The game actually runs on your device, inside the browser.

Big ideaStreaming vs. running

☁️ Cloud streaming

GeForce Now, Xbox Cloud

  • Game runs on a remote PC
  • You receive video
  • Needs fast internet

🧩 Browser port

WebAssembly (Wasm)

  • Game runs on your device
  • Code is rebuilt for the web
  • Near-desktop speed

WebAssembly lets browsers run compiled programs at close to native speed. Figma and Google Earth already use it.

Step 1Decompiling: un-baking the cake

Developers compile readable source code into raw machine instructions. You can’t easily get the recipe back from the finished cake. Decompiling tries to do exactly that.

What’s lostBeforeAfter compiling
NamescalculatePlayerDamage()FUN_00401a3c
StructureClean, readable logicOptimized and scrambled
CommentsExplained intentGone entirely
ScaleOrganized filesMillions of anonymous lines

Traditionally a team of expert reverse engineers needed months or years. Tools like Ghidra handle the mechanical part. The slow part is understanding what thousands of nameless functions do.

Step 2Where AI changes everything

Per Kotaku, modern models like Claude Opus 5.5 are very good at that “understanding” part. An AI can:

1
Read the messy code“This looks like vehicle collision detection.”
↓
2
Name & document itMeaningful names and comments replace FUN_00401a3c.
↓
3
Rewrite it cleanlyReadable, structured source code.
↓
4
Test & fix itself in a loopCompile, run, compare behavior, retry. Overnight, no babysitting.

That loop is the real unlock. It explains the stories: an 18-year-old reportedly got Skate 3 running in a few days, and a self-described non-coder rebuilt Black Ops 2 as “Claude of Duty: Vibe Slops II.”

Step 3Recompiling for the web

With clean source code, the final step is compiling to WebAssembly, typically with a toolchain like Emscripten. The platform-specific parts get swapped for web equivalents:

Original game usedBrowser version uses
DirectX / OpenGL / console GPUWebGL or WebGPU
Native audio systemWeb Audio API
Controller and keyboard driversBrowser input events
Raw network socketsWebSockets / WebRTC

That last row is why one of the four Halo: CE ports Kotaku tried had working online servers with low ping.

PerformanceDoes it actually run well?

Kotaku’s Lewis Parker tried several ports: some were almost flawless, the Simpsons port can hit 240fps, and one Halo: CE port had working online play. Why so fast? An emulator translates every instruction on the fly. A port is a native rebuild, so there’s far less overhead.

The catchWhack-a-mole with lawyers

Dec 2025
Take-Two had DOS Zone pull its Vice City browser version.
Oct 6
A GTA V browser site reportedly vanished within hours of launch.
Oct 8
The @RadiantOpti thread goes viral; Activision and Bethesda also pursue AI-made MW2 and Fallout projects.
Publishers’ real problem: ports are cheap to rebuild. When effort drops from months to days, takedowns stop working. Legally, reverse engineering is a gray zone that varies by country, and distributing copyrighted art, music and code is a separate issue. Some preservation projects ask you to supply your own game files.

TakeawaysWhat to remember

AI’s strength is understanding, not typing. It reads nameless code and works out what it means.
Autonomous loops change the economics. Months of expert labor can run overnight.
WebAssembly is the quiet hero. It made the browser a real game platform.
Preservation gets easier. Games tied to dead consoles and stores could be saved.
Copyright enforcement faces a new reality. It was built for a world where copying was slow.

Sources: Kotaku, @RadiantOpti on X, GodIsAGeek. Figures such as 240fps, the overnight decompiling claim and takedown dates come from those reports; verify against the originals before sharing.
